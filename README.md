## 🛠️ Fitur Utama
- **Otomatisasi H2H:** Inject otomatis saldo game atau terbitkan kredensial akun dalam 3 detik setelah bayar.
- **QRIS Dinamis Otomatis:** Mendukung pembayaran dari seluruh bank & e-wallet Indonesia (BCA, Mandiri, BRI, SeaBank, DANA, GoPay, OVO, ShopeePay).
- **Auto Check Nickname:** Pengecekan nama akun game sebelum checkout agar tidak salah kirim.
- **Admin Executive Dashboard:** Pantau omzet, laba bersih, dan status seluruh invoice.
- **Cloud Ready:** Siap di-deploy 24 jam gratis di **Koyeb** via Docker tanpa perlu laptop menyala.

## 🚢 Panduan Deploy 24/7 ke Koyeb (100% Gratis)

### Langkah 1: Buat Repositori GitHub
1. Buat repo baru di GitHub: `zesha-tech-store`
2. Jalankan perintah di folder ini:
   ```bash
   git init
   git add .
   git commit -m "feat: initial ZTS Hub storefront release"
   git branch -M main
   git remote add origin https://github.com/<username-kamu>/zesha-tech-store.git
   git push -u origin main
   ```

### Langkah 2: Deploy di Koyeb
1. Buka [Koyeb.com](https://www.koyeb.com) dan login dengan akun GitHub.
2. Klik tombol **"Create App"** ➔ Pilih **"GitHub"**.
3. Pilih repositori `zesha-tech-store`.
4. Pilih Builder: **Dockerfile** (Koyeb otomatis mendeteksi `Dockerfile` yang sudah Rexa buat).
5. Pada bagian **Instance**, pilih **Free** (Frankfurt / Washington DC).
6. Klik **"Deploy"**!

Dalam 1–2 menit, toko online Prince Zesha sudah live di URL publik:  
`https://zts-hub-<organisasi>.koyeb.app`
